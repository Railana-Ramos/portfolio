## 💻 Sobre o Projeto

Este repositório abriga o código-fonte do meu portfólio pessoal. O projeto foi construído do zero com foco em performance, acessibilidade e experiência do usuário (UX), destacando minha trajetória acadêmica e profissional como **Desenvolvedora Full-Stack**.

O layout conta com um design moderno, animações fluidas e suporte nativo a múltiplos temas.

---

## 🚀 Funcionalidades

- **Dark Mode Padrão:** Tema escuro nativo ativado por padrão, com opção de alternância para o tema claro através do botão no cabeçalho.
- **Modal de Projetos Dinâmico:** Exibição interativa de detalhes, tecnologias e links externos dos projetos desenvolvidos.
- **Tipagem Estática (TypeScript):** Código estruturado de forma segura e limpa utilizando TypeScript compilado (`tsc`).
- **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops.
- **Animações de Scroll:** Efeitos de revelação suave (`IntersectionObserver`) conforme o usuário navega pela página.

## ⚙️ Como Executar o Projeto Localmente

Se você deseja clonar e testar este repositório na sua máquina, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Railana-Ramos/Railana-Ramos.github.io.git
   ```

2. **Abra a pasta do projeto no seu editor de código (ex: VS Code).**

3. **Se quiser recompilar o TypeScript:**
   Caso faça alterações no arquivo `app.ts`, certifique-se de ter o Node.js instalado e execute o comando de compilação no terminal:
   ```bash
   tsc
   ```

4. **Abra o arquivo `index.html`** no seu navegador ou utilize a extensão **Live Server** do VS Code para visualizar o projeto em execução.
